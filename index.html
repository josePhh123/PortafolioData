/ notas

Notas de arquitectura

nota 01CDC vs. fotos: cuándo usar cada unacaptura→

CDC para tablas transaccionales: captura solo lo que cambia y conserva el historial. Foto para maestras y dimensiones: son pequeñas y más simples de recargar completas.

nota 02Por qué la gold es una estrellamodelado→

Un hecho por proceso de negocio y dimensiones conformadas. El BI hace joins simples y rápidos, y cada medida tiene una sola definición.

nota 03Incremental con versionamiento, full para dimensionescarga→

Los transaccionales crecen y se corrigen: se cargan por incremento, con versión y campos de auditoría. Las dimensiones se recargan completas para no arrastrar deriva.
