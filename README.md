# Portafolio · Joseph Guadalupe (Data Engineer)

Web personal de una sola página: perfil, arquitectura de datos, proyectos, experiencia y stack.
Publicada en https://josephh123.github.io/PortafolioData/

## Cómo verla
- Abre `index.html` directamente en el navegador, o
- sirve la carpeta: `python3 -m http.server 8000` y entra a http://localhost:8000

## Stack
- HTML, CSS y JavaScript sin frameworks ni build (rutas relativas, lista para GitHub Pages).
- Hero animado con Canvas 2D (`assets/js/hero.js`); interacciones en `assets/js/main.js`.
- Tipografías: Archivo + Martian Mono (Google Fonts) con fallbacks del sistema.
- Respeta `prefers-reduced-motion`, navegación por teclado y foco visible.
